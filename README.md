# KAIA DESK

코리아AI아카데미 멘토 업무 앱 — 시간표 · 개강안내 문자 · 학생 · 진도 · 개강/종강 알림을 한곳에서.
휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있어요(PWA).

## 휴대폰에 설치
- **아이폰**: Safari로 사이트 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → 메뉴(⋮) → **앱 설치** (또는 앱의 설정 → 휴대폰 앱으로 쓰기 → 홈 화면에 설치)

## 처음 쓸 때
1. **시간표 → 엑셀 올리기**: 학원 시간표 엑셀(여러 개 한꺼번에 가능)을 올리면 과정 · 휴강일 · 회차가 자동으로 등록돼요.
2. **학생 → 이전 프로그램에서 가져오기**: 이전 학생관리 프로그램에서 내보낸 `.json`을 올리면 학생이 등록되고, 같은 날짜 수업과 자동으로 연결돼요.
3. **설정 → 줌 계정 → 안내받은 내용 붙여넣기**: 회의 ID · 회의 PW만 저장돼요. (이 저장소는 공개라서 코드에는 줌 정보를 넣지 않았어요)
4. **설정 → 강의실 이름**: A · B · C를 "4층 B강의장"처럼 문자에 들어갈 이름으로 바꿔요.

## PC · 휴대폰 데이터 맞추기
기본은 각 기기 안에만 저장돼요. 두 기기에서 같은 데이터를 보려면 [SYNC_SETUP.md](SYNC_SETUP.md)대로 구글 시트를 한 번 연결하세요.

## 파일
| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 |
| `manifest.webmanifest` · `sw.js` | 홈 화면 설치 · 오프라인 실행 |
| `icons/` | 앱 아이콘 |
| `sync/Code.gs` | 구글 시트 동기화용 Apps Script |

학생 개인정보는 이 저장소에 올라가지 않아요. 데이터는 각 기기(또는 본인 구글 시트)에만 저장돼요.
